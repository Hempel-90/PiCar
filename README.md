# PiCar

## Beschreibung

PiCar ist ein Praxisprojekt zur Entwicklung einer autonomen Steuerungssoftware für ein Raspberry-Pi-Fahrzeug. Ziel war die Umsetzung verschiedener Fahrfunktionen mithilfe mehrerer Sensoren sowie die Entwicklung intelligenter Algorithmen zur Hinderniserkennung und Navigation.

## Funktionen

- Autonome Fahrzeugsteuerung
- Hinderniserkennung mit Ultraschallsensor
- Linien- und Fahrbahnerkennung
- Nutzung einer Kamera zur Umgebungsanalyse
- Integration von Grayscale-Sensoren
- Optimierung der Fahrstabilität

## Verwendete Technologien

- Python
- Raspberry Pi
- OpenCV
- Ultraschallsensor
- Kamera
- Grayscale-Sensoren

## Projektziel

Ziel des Projekts war es, praktische Erfahrungen im Bereich Embedded Systems, Sensorik sowie algorithmischer Steuerung zu sammeln und unterschiedliche Sensorinformationen miteinander zu kombinieren.

## Status

Abgeschlossenes Praxisprojekt im Rahmen der Umschulung zum Fachinformatiker für Anwendungsentwicklung.
